# Código de conducta

Este proyecto sigue el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).
En resumen: trata a todo el mundo con respeto, acepta las críticas constructivas con buen ánimo y no toleres el acoso.
Los incidentes se comunican de forma privada a las personas mantenedoras a través del aviso privado de GitHub.
