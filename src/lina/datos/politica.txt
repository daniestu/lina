# ============================================================================================
#  POLÍTICA DE AUTONOMÍA DEL ASISTENTE
#  Qué hace por su cuenta y qué te pregunta antes.
# ============================================================================================
#
#  CÓMO FUNCIONA
#   - El asistente actúa SOLO, sin preguntar, salvo que lo que va a hacer encaje en alguna de las
#     secciones CRÍTICAS de este archivo. En ese caso deja la acción preparada y espera tu confirmación.
#   - Además hay un BLOQUEO DURO en el código (borrar el sistema, formatear discos, leer claves,
#     descargar y ejecutar scripts de internet...). Eso no se puede desbloquear desde aquí ni diciendo que sí.
#   - Solo LEER algo (cat, ls, grep...) nunca es crítico, aunque sea una ruta crítica.
#   - Se relee solo al guardar el archivo: NO hace falta reiniciar. Si te equivocas al escribir, el registro
#     del asistente (journalctl --user -u lina) te avisa de qué línea es y usa los valores de fábrica
#     de la sección que falte.
#   - Este archivo lo protege el código: el asistente NO puede modificarlo por voz. Lo que se pregunta y lo
#     que no lo decides tú, a mano.
#
#  FORMATO de las líneas dentro de cada sección crítica  (una regla por línea; # para comentarios):
#     motivo TEXTO                      lo que se te dice al pedir confirmación
#     programa NOMBRE                   cualquier uso de ese programa (admite *, por ejemplo  mkfs.*)
#     subcomando PROGRAMA PAL1 PAL2     ese programa con alguna de esas palabras (btrfs balance)
#     bandera PROGRAMA OPC1 OPC2        ese programa con alguna de esas opciones (pacman -U)
#     ruta PATRON                       si el comando modifica algo en esa ruta. Admite *; sin * incluye
#                                       todo lo que haya dentro. ~ es tu carpeta personal.
#     servicio UNIDAD                   systemctl start/stop/restart/enable/disable... de ese servicio
#     paquete PATRON                    instalar o quitar ese paquete con pacman, paru o yay
#     ejecutar_desde RUTA               ejecutar un programa o script que esté en esa ruta
#
#  PERFIL Y ATAJOS
#   - El perfil (autonomo, equilibrado o prudente) y los interruptores por categoría están en config.toml, sección [autonomia]
#     (lina config perfil prudente). Se aplican ENCIMA de este archivo: pueden apretar el modo o aflojar categorías, pero
#     discos, arranque, cuentas, dinero y gasto se confirman siempre.
#
#  CÓMO AJUSTARLO
#   - ¿Quieres que te pregunte MENOS por algo? Borra la línea (o la sección entera).
#   - ¿Quieres que te pregunte MÁS? Añade líneas, o cambia  autonomia  a  prudente  (abajo).
#   - Si dejas una sección sin ninguna línea, esa categoría queda sin vigilar.
# ============================================================================================
